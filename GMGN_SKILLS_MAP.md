# GMGN Skills Map

## Umbrella

- `gmgn-analysis-suite`
  - Full project-level GMGN analysis
  - Best starting point for broad token research or cross-domain analysis

## Market

- `gmgn-market-intel`
  - Trending tokens
  - Hot searches
  - Trenches
  - Signals

- `gmgn-market`
  - Focused market discovery and ranking

- `gmgn-market-workflow`
  - Combined workflow across market, token, wallet, orders, and launchpad

## Token and Pump.fun

- `gmgn-token`
  - Token info, security, holders, traders, pool

- `gmgn-pumpfun-data`
  - Pump.fun extraction and monitoring

## Wallet

- `gmgn-wallet-intel`
  - Portfolio, holdings, activity, smart money, KOL

- `gmgn-portfolio`
  - Wallet holdings and performance stats

- `gmgn-track`
  - Wallet feeds, smart money, KOL, watchlists

## Execution

- `gmgn-launch-intel`
  - Swaps, strategy orders, cooking, launchpad actions

- `gmgn-swap`
  - Token swap execution

- `gmgn-cooking`
  - Launchpad token creation flows

## Notes

- Use the narrow skill when the question is specific.
- Use `gmgn-analysis-suite` when the task spans multiple GMGN categories.
- The new `gmgn:*` npm scripts are wired to the local wrapper commands in `/scripts`.
