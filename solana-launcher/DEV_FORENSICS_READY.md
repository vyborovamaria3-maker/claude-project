# Dev Forensics Analytics - Готово к тестированию

## Что реализовано

### ✅ API `/api/trade/dev-forensics`
- **QuickNode RPC интеграция** для надежного mainnet доступа
- **DefiLlama API** для исторических объемов Solana
- **Pump.fun API** для детальной информации о токенах
- **Полная аналитика токенов dev wallet**:
  - `totalCreatedTokens` - всего создано токенов
  - `totalMigratedTokens` - всего мигрировало токенов  
  - `migrationRate` - процент миграции
  - `avgLifespanHours/Minutes` - среднее время жизни
  - `medianLifespanHours/Minutes` - медианное время жизни
  - `successRate` - процент токенов достигших $100k MC
  - `lifetimeDistribution` - распределение по времени жизни
  - `bestToken/worstToken` - лучший/худший токены по ATH
  - `volumeCorrelation` - корреляция с объемом Solana
  - `optimalVolumeRangeM` - оптимальный диапазон для запуска

### ✅ UI - Новая вкладка "Dev Forensics"
- **Отдельная вкладка** в BottomTabs между Analytics и Top Traders
- **Русский интерфейс** полностью на русском языке
- **Интерактивные диаграммы**:
  - Donut chart: Created vs Migrated токены
  - Bar chart: Распределение времени жизни токенов
- **Детальная статистика**:
  - Ключевые метрики в карточках
  - Лучший/худший токены с деталями
  - Корреляция с объемом Solana
  - Полный список всех токенов с таблицей
- **Оптимальное время запуска** с рекомендациями

### ✅ Порог миграции
- Установлен **$35.65k MCAP** как порог миграции pump.fun
- Используется **createdAt** для времени запуска
- Используется **ATH price** для анализа роста

## Как протестировать

### 1. Настройка окружения
Добавьте в `.env.local`:
```
NEXT_PUBLIC_QUICKNODE_RPC_URL=https://solana-mainnet.g.alchemy.com/v2/QN_4ae4c43cd2e143048868d499f5f77b98
```

### 2. Запуск
```bash
npm run dev
```

### 3. Тестирование
1. Откройте любой токен на странице `/trade/analysis`
2. Перейдите на вкладку **"Dev Forensics"**
3. Ожидайте загрузку 10-15 секунд (API делает много запросов)
4. Проверьте отображение:
   - Общая статистика (всего создано/мигрировало)
   - Диаграммы
   - Лучший/худший токены
   - Корреляция с объемом Solana
   - Таблица всех токенов

## Что осталось реализовать

### 🔄 Средний приоритет
- **Twitter/X анализ** через Nitter scraping
- **SQLite shiller database** для аккаунтов
- **Bot detection** (только пометка, не исключение)
- **Paid promoter определение** (статистика, проценты, иксы)

### 🔄 Низкий приоритет  
- **Whitelist/blacklist** для Twitter аккаунтов

## Технические детали

- **Cache TTL**: 10 минут для dev-forensics API
- **Rate limiting**: 6 параллельных запросов для избежания лимитов
- **Fallback источники**: pump.fun → DexScreener → DefiLlama
- **Обработка ошибок**: Graceful degradation при недоступности источников
- **Performance**: Оптимизировано для до 50 токенов на dev wallet
