# Master Skills Index

## GMGN
- `gmgn-cooking`: launchpad creation and token launch workflows.
- `gmgn-market`: market discovery, trending, trenches, signals.
- `gmgn-portfolio`: wallet holdings, P&L, and dev-created tokens.
- `gmgn-swap`: swaps, orders, gas, and execution flows.
- `gmgn-token`: token info, security, holders, traders, pool.
- `gmgn-track`: smart money, KOL, watchlists, tracked wallets.
- `gmgn-market-workflow`: umbrella analysis skill for discovery, token checks, wallet checks, orders, and launchpad flows.
- `gmgn-pumpfun-data`: Pump.fun-specific extraction, export, and monitoring.
- `gmgn-analysis-suite`: full GMGN analysis suite for market, token, wallet, signals, execution, and launchpad flows.
- `gmgn-market-intel`: market-only GMGN discovery skill.
- `gmgn-wallet-intel`: wallet-only GMGN analysis skill.
- `gmgn-launch-intel`: execution and launchpad GMGN skill.

## Product / Web
- `web-product-workflow`: site architecture, scraping, and React UI components.

## Design / Frontend helpers
- `impeccable`: advanced visual polish and interface design workflows, validated locally.
- `taste-skill`: design taste and aesthetic transformation helpers.
- `redesign-skill`: redesign and UI refresh workflows.
- `stitch-skill`: combining UI patterns and presentation systems.

## Notes
- Project skills should live in `.agents/skills`.
- Global skills live in `~/.codex/skills`.
- Prefer the narrowest skill that matches the task; use the umbrella GMGN skill for cross-cutting analysis.
