# Исторический сбор X

Во вкладке «Аккаунты» у collector нажмите «Архив за 2 года». Источники:

- текущие участники включённых списков из `xc_auto_sources`: их доступные публикации за два года без фильтра тем;
- отдельный поиск на русском и английском по мемкоинам, мемам, политике, Илону Маску и Дональду Трампу, в том числе публикациям `elonmusk` и `realDonaldTrump`.

Период фиксируется при запуске: два календарных года до текущей даты Москвы, включая текущий день. X получает даты `since` / `until` в UTC, верхняя граница исключающая. Сбор работает через сессию и прокси выбранного collector, учитывает занятость и часовую квоту. Квота new 15 позволяет пять поисковых проходов в час; чтение участников списка также расходует квоту. Квота автоматически не повышается.

Сначала читаются страницы участников списков. Авторов сохраняем в `xc_history_authors`. История разбита на календарные месяцы. Поиск читает до 100 записей за проход. При достижении лимита создаётся следующий проход того же периода с `max_id` меньше минимального сохранённого ID. Даты, автор и курсор проверяются до записи в базу. Если X игнорирует фильтры и курсор не продвигается, период помечается неполным.

`xc_history_runs`, `xc_history_lists`, `xc_history_windows` и `xc_history_tasks` хранят очередь и прогресс. Пауза останавливает новые задания; уже начатый запрос может завершиться. «Продолжить архив» возобновляет работу, «Повторить ошибки» возвращает неуспешные периоды и списки в очередь. Дубликаты твитов обновляются по ID.

Основные данные записываются в `twitter_tweets`, а постоянные снимки архива — в `xc_history_posts.snapshot_json`. Постоянные снимки сохраняются при очистке операционных задач и основной таблицы твитов. Метрики относятся к моменту наблюдения, а не к дате публикации. Фото/видео сохраняются ссылками, файлы медиа не скачиваются.

Подготовка и запуск:

```powershell
npm run build
npm run migrate
node scripts/history-collector.cjs
```

Приложение запускает исторический процесс через кнопку. Он автоматически запускает обычный collector worker при появлении архивных задач. При следующем запуске `autopost-worker.cjs` активный исторический сбор также возобновляется. Прогресс сохраняется в PostgreSQL, но после перезагрузки компьютера приложение/worker нужно запустить снова.

Браузерный поиск даёт доступные результаты, а не гарантированную полную копию X. Удалённые, закрытые и не попавшие в выдачу записи могут отсутствовать. Списки участников отражают текущий состав: вышедшие ранее участники не восстанавливаются автоматически. Тематический охват определяется перечисленными поисковыми запросами; это не поиск всей мировой политики и всех мемов. Ошибки и неполные периоды показаны отдельно.
