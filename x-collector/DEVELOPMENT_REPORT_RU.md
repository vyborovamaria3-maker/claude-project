# Проверка X Collector — 2026-10-08

## Исправления

- Vue и Chart.js загружались с CDN, запрещённых действующей CSP. Теперь это зависимости с lockfile, раздаваемые dashboard по фиксированным локальным маршрутам. Политика не расширена до внешних доменов. Vue runtime compiler по-прежнему требует существующий unsafe-eval; inline application script требует unsafe-inline.
- Общий Promise.all скрывал все результаты при сбое одного endpoint. Запросы теперь обновляют данные независимо, показывают ошибки по endpoint, сохраняют последний успешный результат и очищают ошибку после восстановления. Есть таймаут, защита от наложения refresh и ручное обновление.
- Все восемь вкладок открываются; URL hash и переходы назад/вперёд синхронизированы. График уничтожается при уходе с Mint и создаётся заново после возвращения. Поздний ответ предыдущего mint-запроса не заменяет новый.
- Добавлены вывод популярных слов, собранных постов и всплесков. Отсутствие summary явно отображается; отсутствие вероятности ML не выдаётся за нулевую вероятность.
- API проверяет mint/handle/granularity и возвращает 400 вместо неясной ошибки 500. Изменяющие маршруты требуют POST и same-origin, включая loopback. Basic Auth и ограничения внешнего bind сохранены.
- SQL deferTask воспроизводимо падал с `operator is not unique: unknown + unknown`. Добавлены bigint casts в арифметику defer/retry/cooldown. Проверки выполняют production SQL через адаптер транспорта.
- Исправлены имена полей результата detect_coordination для соответствия TypeScript-интерфейсу.
- migrate --status больше не создаёт schema_migrations.
- README исправлен: 003 существует, но представляет реконструкцию, а не найденный оригинал. Исторический FIX_REPORT_RU.md сохранён с пояснением.
- Добавлен отдельный CI для подсистемы.

## Проверки

Успешно выполнены `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `git diff --check`.

43 теста прошли без пропусков. Новые сценарии:

- Chromium/Playwright с настоящими локальными Vue и Chart.js и CSP: все вкладки, отказ одного API, независимый digest, восстановление API, Mint chart после возврата. API-ответы в браузерном тесте контролируемые; это тестовый fixture, не источник данных приложения.
- HTTP: отсутствующий mint → 400, GET rebuild → 405, внешний Origin POST → 403.
- Все 11 миграций исполняются на disposable PGlite с pg_trgm; optional pgvector отсутствует и пропускается предусмотренной миграцией. Индексы 003 существуют, повторное применение успешно. Основные views, daily digest, hype/ultra rebuild, history capture и retention dry-run выполняются.
- Реальные функции backend через транспортный адаптер к PGlite: dashboard analytics readers, полный пустой Mint report, task dedup, ownership, defer без потери попытки, reclaim истёкшей аренды, retry, DLQ, account exclusivity и cooldown.
- AES-GCM: случайный IV, round-trip, отклонение подмены ciphertext и неверного ключа.

PGlite использует PostgreSQL engine, но не проверяет обычный сервер PostgreSQL, сетевые сбои, права, pgvector, межпроцессный SKIP LOCKED/advisory locking и production-планы запросов. Эти проверки остаются обязательными на выделенной тестовой БД перед развёртыванием. Production-БД, X-аккаунты и уведомления не затрагивались.

## Настройка перед запуском

Выделенная DATABASE_URL, постоянный MASTER_KEY, интерактивный X login, worker и scheduler в отдельных процессах. Для внешнего dashboard нужны Basic Auth, DASHBOARD_ORIGIN и TLS reverse proxy. Для накопления истории должен регулярно работать scheduler. Для внешних providers и уведомлений нужны выбранные источники и доступы. Ограничения X не обходились.

Полностью завершённой production-системой этот результат не объявляется: автоматический mint-feed, S3 архиватор и финансовые исторические данные остаются отдельными незавершёнными интеграциями.
