# Аудит потенциально неиспользуемого кода

Knip используется как диагностический инструмент для ревью и как блокирующая
CI-проверка потенциально неиспользуемых файлов. Результат означает, что файл
не достижим из настроенных entrypoints; это не автоматическое разрешение на
удаление.

Перед удалением проверяем статические и динамические импорты, `npm run`,
cron/Task Scheduler и внешние CLI. После каждой группы удаления обязательны
typecheck, lint, build и тесты.

Первый этап показал крупный legacy-слой в `lib/intelligence/`; текущая
реализация intelligence находится в `src/intelligence/`. Оставшиеся legacy
модули являются compatibility layer и удаляются только после проверки
статических/динамических зависимостей и полного CI.
