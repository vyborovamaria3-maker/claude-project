# Аудит потенциально неиспользуемого кода

Knip используется только как диагностический инструмент. Результат означает,
что файл не достижим из настроенных entrypoints; это не автоматическое
разрешение на удаление.

Перед удалением проверяем статические и динамические импорты, `npm run`,
cron/Task Scheduler и внешние CLI. После каждой группы удаления обязательны
typecheck, lint, build и тесты.

Первый этап уже показал крупный legacy-слой в `lib/intelligence/`; текущая
реализация intelligence находится в `src/intelligence/`. Оставшиеся legacy
модули удаляются отдельными наборами после проверки зависимостей.
