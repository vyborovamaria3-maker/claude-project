# Examples

## Architecture prompt

```text
Build a sitemap and page structure for a SaaS dashboard that helps teams track design reviews.
```

Expected output:

- audience and goal summary
- top-level navigation
- page hierarchy
- content blocks per page
- open questions

## Scraping prompt

```text
Extract product name, price, rating, and availability from this marketplace listing page.
```

Expected output:

- source and access method
- selector or request strategy
- field schema
- pagination plan
- dedupe and failure handling

## React UI prompt

```text
Create a responsive product card component with image, title, price, badge, and CTA.
```

Expected output:

- component tree
- props
- state
- responsive behavior
- accessibility notes
- implementation details
