# Token Analysis

## Recommended field set

- token name and symbol
- mint address
- chain
- launchpad and platform
- price and percent change
- volume, liquidity, market cap
- holders and top-holder concentration
- swaps, buys, sells
- creator and creator status
- security flags
- live status and migration state

## Useful thresholds

- High risk: top-holder concentration above 20%
- Watchlist: liquidity below the project norm
- Momentum: strong 5m trend with rising volume
- Caution: high bundler rate or fresh-wallet concentration
- Potential exploit: security flags, honeypot, or abnormal wash-trading signals

## Interpretation order

1. What is the asset?
2. Is it tradable and live?
3. Is liquidity healthy?
4. Is ownership concentrated?
5. Is momentum real or noisy?
6. What is the likely next action?
