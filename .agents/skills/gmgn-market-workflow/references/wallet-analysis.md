# Wallet Analysis

## Wallet views

- Holdings: what the wallet owns now.
- Activity: what the wallet traded recently.
- Stats: how the wallet performed over time.
- Follow-wallet: what the wallet is doing now.

## Copy-trade review

- Start with 30d stats.
- Check holdings for survivorship bias.
- Inspect activity for frequency and style.
- Compare profits against drawdown and trade count.
- Avoid copying wallets with noisy one-off wins only.

## Watchlist review

- Sort by market cap or created time when hunting discovery.
- Sort by price change when hunting momentum.
- Use group filters when the wallet maintains organized lists.
