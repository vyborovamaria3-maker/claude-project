# Command Map

## Market discovery

- Trending: top movers for a chain and interval.
- Hot searches: fast-rising attention signals.
- Trenches: newly created or migrated tokens.
- Signals: event-based market indicators.

## Token analysis

- Info: core token metadata.
- Security: risk checks and contract flags.
- Kline: OHLC and time series analysis.
- Pool: liquidity and pool health.
- Holders: concentration and distribution.
- Traders: realized and unrealized trading behavior.

## Wallet and tracking

- Holdings: current wallet positions.
- Activity: trade history.
- Stats: P&L performance.
- Token balance: position size for one asset.
- Follow-wallet: tracked wallet feed.
- Follow-tokens: watchlist feed.

## Orders and launch

- Swap: buy/sell spot execution.
- Multi-swap: batched execution.
- Strategy orders: limit, TP/SL, trailing, cancel, list.
- Cooking: launchpad creation for supported chains.

## Default presets

- Discovery: `sol`, `5m`
- Token review: `sol`, `1m`
- Wallet review: `sol`, `30d`
- Launchpad: match the chain to the target platform
